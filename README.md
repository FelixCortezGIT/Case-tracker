# Case Tracker

Case Tracker is a web-based application for managing and tracking cases throughout their lifecycle.

The system allows users to create cases, update statuses, manage deadlines, add notes, and maintain a complete activity history.

## Features

- Case creation and management
- Status tracking
- Deadline monitoring
- Notes management
- Activity logging
- Queue-based workflow

## Tech Stack

- Python
- Flask
- PostgreSQL
- SQLAlchemy
- Jinja2
- HTML/CSS/JavaScript
- Bootstrap
